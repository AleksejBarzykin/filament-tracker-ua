# КОТУШКА.UA

Моніторинг цін на філамент для 3D-друку в українських інтернет-магазинах
(доставка по Києву/Україні): таблиця з фільтрами по матеріалу/бренду/кольору/
магазину/ціні, історія ціни по кожній позиції, бейджі акцій та підписка на
email-сповіщення про зниження ціни.

## Стек

- Next.js (App Router) + TypeScript + Tailwind CSS 4
- Prisma + SQLite (`prisma/dev.db`, комітиться в репозиторій — див. нижче)
- Cheerio-скрапери магазинів (`scripts/scrapers`)
- Recharts для графіка історії цін

## Розробка

```bash
npm install
npm run db:push     # створити/оновити schema.prisma -> prisma/dev.db
npm run db:seed      # заповнити демо-даними (реалістичний приклад, без мережі)
npm run dev
```

## Реальний скрапінг цін

Скрапінг реально запускався в GitHub Actions (є доступ в інтернет, на
відміну від sandbox-середовища розробки) і селектори підібрані та перевірені
за фактичним HTML магазинів, отриманим із логів CI. Станом на останній
прогін (`npm run scrape`) — реальні дані по кожному магазину:

| Магазин | Статус | Позицій |
| --- | --- | --- |
| ArtLine | ✅ працює | 144 |
| UKR3D | ✅ працює | 20 |
| 3DPlastic | ✅ працює | 4 |
| OLX | ⚠️ частково | 1 (класифайд, штучні збіги) |
| Plexiwire | ❌ 0 | сторінка вантажиться (Horoshop-платформа), але клас картки товару ще не підібраний |
| Filament-Shop.in.ua | ❌ 0 | на головній немає списку товарів (лише слайдер) — потрібна пряма посилання на каталог |
| Brain | ❌ 403 | блокує запит, схоже на WAF/anti-bot повноцінного рівня |
| Rozetka | ❌ 403 | те саме |

```bash
npm run scrape             # усі магазини
npm run scrape -- plexiwire  # окремий магазин (ключ з scripts/scrapers/shops/index.ts)
npm run check-notifications  # перевірити підписки на знижку і "розіслати" (зараз лише лог, TODO нижче)
```

Живий скрапінг і оновлення даних на проді керуються GitHub Actions:
`.github/workflows/scrape-prices.yml` щодня ганяє скрапери на раннері з
відкритим інтернетом і комітить оновлений `prisma/dev.db` назад у
репозиторій. Коли якийсь магазин повертає `0 listings`, скрипт сам друкує в
лог `[debug]`-фрагмент реального HTML навколо ціни/картки товару — це
основний інструмент діагностики, ним і підбирались усі селектори вище.

### Що доробити для продакшена

- **Plexiwire / UKR3D (PLA-група)**: обидва на платформі Horoshop; для PETG
  на UKR3D картка знайдена (`.catalogCard-box`), а для Plexiwire — ще ні
  (жоден із опробуваних маркерів у `run.ts` не збігся). Наступний крок —
  запустити `npm run scrape -- plexiwire` в CI і подивитись `[debug]`-вивід
  саме для нього.
- **Filament-Shop.in.ua**: точка входу (головна сторінка) — це просто банер,
  без товарів. Потрібно знайти реальний URL каталогу (в навігації сайту) і
  підставити в `scripts/scrapers/shops/index.ts`.
- **Brain / Rozetka**: обидва повертають HTTP 403 навіть із браузерним
  User-Agent — це повноцінний WAF/anti-bot, а не банальна перевірка
  заголовків. Просте рішення (заміна User-Agent, cookie-обхід) тут не
  спрацює — знадобиться headless-браузер (Playwright) з реальним рендерингом
  сторінки, що суттєво важче й довше в CI. Це свідома пауза, не помилка.
- **OLX**: дошка оголошень, а не магазин — знайдена всього 1 позиція за
  ключовим запитом, і зв'язок із конкретним брендом/матеріалом ненадійний
  (індивідуальні оголошення без стандартизованого опису). Далі можна
  покращувати, але точність тут завжди буде нижчою, ніж у звичайних
  магазинів.
- **Відправка email**: `scripts/check-notifications.ts` зараз лише логує, кому
  й що треба надіслати — підключити провайдера (Resend/Postmark/SMTP) в
  позначеному `TODO`.
- **Бренди**: список відомих виробників (для розпізнавання з назви товару) —
  `scripts/scrapers/utils.ts` (`KNOWN_BRANDS`), включно з Creality, Bambu Lab,
  Elegoo, Kingroon, SUNLU, eSUN та ін.
- Якщо деплоїш не на платформу з персистентним диском для SQLite — постав
  `DATABASE_URL` на зовнішню Postgres-базу і онови `datasource` у
  `prisma/schema.prisma` (`provider = "postgresql"`), або тримай `dev.db` як
  read-only снапшот, що оновлюється екшеном (поточна схема).
